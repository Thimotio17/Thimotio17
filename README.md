---

                                                                      Sobre mim

Sou apaixonado por tecnologia e desenvolvimento de sistemas, sempre buscando transformar problemas reais em soluções simples, eficientes e fáceis de manter.

Minha experiência envolve o desenvolvimento **Full Stack**, utilizando tecnologias modernas para construir aplicações web, APIs e sistemas personalizados.

No **Frontend**, trabalho principalmente com **React, TypeScript, JavaScript, Vite e Tailwind CSS**, criando interfaces responsivas, organizadas e com boa experiência de uso.

No **Backend**, utilizo **Node.js, Express e TypeScript** para desenvolver APIs, regras de negócio, integrações e serviços.

Também tenho experiência com **PostgreSQL, MongoDB, Docker, Linux, Git e GitHub**, além de ferramentas e ambientes voltados para desenvolvimento e implantação de sistemas.

Gosto de entender como cada parte de uma aplicação se conecta — do banco de dados à interface — e busco constantemente melhorar meus conhecimentos em arquitetura, desempenho, organização de código e boas práticas de desenvolvimento.
